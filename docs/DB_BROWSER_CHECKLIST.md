# DB Browser for SQLite — Stage 4

1. Start the FastAPI app so `tasks.db` is created automatically.
2. Open `tasks.db` in DB Browser for SQLite.
3. Open **Browse Data** and select the `tasks` table.
4. Run `SELECT * FROM tasks;` in **Execute SQL**.
5. Confirm the rows match the API's `GET /tasks` response.
6. Take a genuine screenshot of DB Browser showing the `tasks` table and save it as `docs/db-browser.png`.

The screenshot must be taken from the user's actual DB Browser session; do not use a generated or placeholder image.
